# NoteHub 🧠

NoteHub is a high-performance, lightweight note-taking workspace that merges frictionless plain-text Markdown editing with powerful visual tools like spatial canvases and relational graph views. 

Designed to operate as a "second brain," NoteHub moves beyond traditional folder structures by allowing users to connect ideas visually, sketch architectures via a built-in drawing engine, and manage daily workflows through an integrated calendar. 

## ✨ Features
* **Markdown Editor:** Fast, distraction-free text entry with real-time formatting.
* **Relational Graph View:** Interactive node-based visualization of note connections.
* **Spatial Canvas:** Infinite whiteboard for freehand drawing and diagramming.
* **Calendar Integration:** Time-blocked daily notes and deadline tracking.
* **AI Integration:** Context-aware assistant for summarizing and brainstorming.
* **Cross-Platform:** Responsive desktop web app compiled to native mobile (iOS/Android) via Capacitor.

## 🛠️ Tech Stack
* **Frontend:** React, TypeScript, Vite
* **Mobile Bridge:** Capacitor
* **Visual Integrations:** TLDraw (Canvas), D3.js (Graph View), FullCalendar
* **State Management:** Zustand
* **Backend / Auth:** Firebase 

## 🚀 Getting Started
1. Clone the repository: `git clone https://github.com/yourusername/notehub.git`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Build for mobile: `npm run build:mobile`
